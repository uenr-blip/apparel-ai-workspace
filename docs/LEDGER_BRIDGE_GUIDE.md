# 业务与总账贯通

入口：财务与对账 → 会计账务 → 业务入账（原记账衔接，/finance?tab=bridge）。用户已确认本轮优先贯通业务与总账，不扩展正式税务规则或真实银行交易。

## 如何使用

1. 先选择演示账套。没有账套时进入「总账」创建；同一业务在不同账套的记账状态分别计算。
2. 通过订单号、款项、流水号、来源类型和处理状态查找。列表包含应收应付原单、独立扣补、原始收付款、退款和换汇；退款/换汇产生的内部资金腿不会重复列为新的入账来源。
3. 点击业务来源，查看当前状态、本账套全部关联凭证及反向凭证历史。待制单来源可直接打开固定来源的制单弹窗，核对科目、日期、汇率和依据；不再重新搜索并手选同一来源。
4. 保存后状态变为凭证草稿；由另一账号复核后变为待过账，办理过账后回到业务单据可以看到凭证号。已过账凭证仍不能直接修改，原有反向凭证流程保留。
5. 应收应付详情和外贸订单详情显示记账概览；普通业务订单在「本单财务与记账状态」展开查看。收付流水和退款/换汇列表均提供来源入口。总账账套和凭证详情可以返回衔接清单或业务原件。

## 状态与处理

| 状态 | 含义与下一步 |
| --- | --- |
| 待制单 | 本账套没有有效关联凭证；核对是否需要入账，再明确科目与依据 |
| 凭证草稿 / 待过账 | 已制单，分别等待复核或过账 |
| 已过账 | 本来源已过账，且本轮可核对的来源依赖未发现变化；不代表全业务与总账余额已对平 |
| 冲销处理中 | 已有未完成过账的反向凭证，原凭证仍有效 |
| 已冲销 · 待重新核对 | 反向凭证已过账；需要重新判断并制单时，不复制原历史 |
| 来源待核对 | 业务原件与制单快照不同，或收料/采购/加工依据变化而应付尚未跟进 |
| 业务待确认 / 来源已失效 | 业务草稿或失效登记不能当作可正常制单的有效来源 |

例如：收料100米，按2.50元确认250元应付并过账；单价改成3元后，衔接页提示来源待核对。经原收料页面核对应付差异后，原250元凭证保留，新增50元独立扣补进入待制单。后续扣补不会把原凭证静默改为300元。旧依据未处理时，服务端也拒绝继续用它生成、复核或过账来源凭证。

## 订单、资金与金额边界

应收应付和扣补直接关联订单。收付流水按有效核销关联订单，退款/换汇沿原流水继承关联关系；撤回核销后不再显示为该订单的当前关联资金。没有核销的资金可在全局清单找到。

一笔流水可能关联多张订单，因此订单视图里的资金金额是整笔来源金额，不是本单分摊金额，不按订单重复合计。不同币种分开显示；本页计数统计来源条数，不生成虚假的原币混合金额或“业务与总账已对平”结论。

## 权限与性能

衔接视图要求同时拥有外贸财务查阅和总账查阅权限，后台重查当前账号、角色和组织。制单、复核、过账仍分别授权；仅有查阅权限不能通过新入口获得写权限。来源与账套必须属于当前组织。

列表每页20条，筛选和计数在数据库内完成；来源凭证历史每页20条，订单摘要显示前6条并提供全部入口。收料/采购/加工依赖按批查询，每批400张，上限5000张来源单据；超过时明确拒绝给截断结论，应从具体订单进入。实测收料来源1张与21张均为2次查询，不逐单查询。这不是生产容量验收。

## 尚未覆盖

- 耗用、出运、成本结转、核销等事件尚无完整的自动记账映射，手工凭证也不会自动认领业务来源。因此待处理清单为空不证明全业务没有漏账。
- 订单业务成本、往来辅助余额、银行余额与总账尚未实现全面金额对账。当前新增的是来源关联、记账状态及已接入来源的依赖检查。
- 正式会计税务规则、期初核验、期末重估、损益结转、法定报表和财务实际业务验收仍待后续。

上线条件见 [OPS_READINESS.md](OPS_READINESS.md)。私用环境的验证记录不随源码发布；原演示库不写入隔离测试账目。

金额核对更新：会计区已增加公司总额及来源凭证金额核对，规则和未覆盖范围见 [MONEY_RECONCILIATION_GUIDE.md](MONEY_RECONCILIATION_GUIDE.md)。当前仍不是逐往来辅助账或外部银行余额的全面验收。
