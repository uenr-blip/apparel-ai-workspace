# 实物凭证到订单成本

入口：资源中心「收料与退补」；财务「订单成本」。本轮仍是业务核对，不下达正式采购、不发起银行支付、不会自动进行总账过账；来源记账经独立总账流程办理，见 [LEDGER_GUIDE.md](LEDGER_GUIDE.md)。

- 实际收料生成独立批次，记录订单、供应商、原始单位、数量、日期、凭证号与验收依据。只办理公司材料已验收放行的收料。重复凭证号被拦截。
- 对应已有在途时必须选择批次，减少原在途数量，本订单预留随到货移入现货。部分到货不能动用其他订单预留。领用本单已占材料时，占用随实际耗用递减。
- 数量最多3位小数，不自动换单位；实际可用日期使用实时日期。财务单独确认计价，单价最多6位小数，保留计价版本。价格修订后当前业务成本重算，应付差异另行确认，币种不能直接更换。
- 按净收料和单价建立材料应付；采购草稿与实际收料不能重复形成同笔应付。收料来源的退补通过原实物/计价差异办理，避免自由扣补与批次成本不一致。
- 调拨保留来源。材料可供不同订单使用，实际耗用分别归单；未耗用退回增加在手并减少本单净耗用，退供减少净收料并形成应付差异。
- 冲销保留正反凭证，库存、占用、已核销金额或下游依赖不满足时拒绝。先处理核销、应付、退供、调拨与领用，再冲销原收料。在途收料冲销恢复原在途数量，预留不自动重建。解除本单占用有审计，在手不变。
- 历史领用可以补归单和计价，不再次扣料。已归单不能直接改属另一订单；须先冲销重登。缺计价、未归单不计成零成本。
- 材料成本按订单/来源批次净耗用×当前单价，加工按已确认加工应付，其他费用明确选入。材料采购全额、订金和付款不重复计成本。不同币种分列。

金额沿用业务凭证口径，税务尚未拆分；不代表完整订单利润、正式存货估值或会计关账。未归单、缺价和间接费用仍需核对。

经理单独下发收料、实物退补权限；计价和应付差异需外贸查阅+业务确认，历史归单需查阅+单据登记。工厂仅能将本厂耗用归入本厂负责订单，不能读公司材料金额。

明细20条/页，来源批次最多100条，历史最近20条；单订单成本最多计算5000个来源，超过即拒绝截断合计，页面展示前100项并标明总数。生产容量尚未验收。

用户已选择在衣据内建设总账，但目前仅有一线流程，尚未与真实财务确认。可配置演示账套、科目、本位币、期间、凭证及试算表已实现；演示配置不视为真实会计准则。总账不会把当前业务成本汇总直接当作正式成本分录。税率和出口退税规则不写死。

原币来源退款与结汇登记已接入「资金调整」；坏账、复杂退款和真实银行交易仍未实现。已核销后的退料会留下待处理差异，不伪称已经退款。
