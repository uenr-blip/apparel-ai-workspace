# 演示案例与预期结果

全部为虚构开发测试资料；任何数量、价格、公司名、日期都不是客户实际事实。

## 固定参考与数据原则

固定演示参考日期为2026-09-18，时区Asia/Shanghai。日期不随页面刷新漂移；测试可注入时钟。实际系统使用组织配置时区，不依浏览器猜测交期。

主组织：演示服装公司；客户：北岸服饰；工厂：云杉服装工厂；供应商：青禾面料。另建隔离组织与第二工厂验证权限。名称都必须带演示说明。

最少12个不同款式、20个材料、3个客户、4个供应商/工厂、8笔订单。开发中/销售样/翻单/缺料/待批准/部分出货场景来自同一关系模型，首页不能另造统计。

## 场景一：翻单资料成为可审核的动作

**历史记录**：主款ST-26018“圆领针织上衣”，存在旧订单和已批准技术资料V1。旧版袖口不是本次要求的罗纹版本。旧客户PO不可沿用为新客户PO。

**输入**：fixtures/01-reorder.txt。

**第一轮正确输出**：识别旧款候选；本次两色合计1000；PO缺失；尺码比例未知；罗纹规格及其确认未知；交期原文写10月20日，根据演示上下文可提出2026-10-20候选，但年份需展示推断依据/确认，不可作为无来源已提取事实。

**允许执行**：经过用户批准，创建订单草稿、技术资料V2草稿、补齐尺码与罗纹规格任务，全部关联输入来源。

**不允许执行**：创建重复主款；修改历史订单；自动沿用旧PO；生成正式生产单；宣称颜色/材料已批准；虚构尺码。

**第二轮人工补充**：海军蓝XS/S/M/L/XL=60/120/240/120/60；灰色40/80/160/80/40。合计分别600和400。人工选择交期2026-10-20；补充材料规格，经过明确批准形成新版本。接下来才能按适用BOM进行正式采购核算。

## 场景二：净需求与余料方案

**统一前提**：1000件、相同已确认材料规格、单耗1.5米/件、不含采购加成，另加3%；实际同一材料合格在库170米，其中50米已给其他订单占用，所以本单可分配120米。

**在途**：200米，预计到货不晚于需求日期；未给其他需求占用；到货使用仍须满足实际收货/质检。规划时可以作为及时供给；未收货不能计作现货，更不能直接发料。

**供应条件**：MOQ300米，采购倍数10米，20.00元/米。上述条件均作为演示报价记录存在，而不是模型凭空返回。

**方案A**：使用120米可分配库存+200米及时在途，补购1230米，采购行24600.00元。1545毛需求，采购及已有供应共1550米，多出5米应标为本次计划结余，不提前伪装为实际库存。

**方案B**：在保留200米及时在途的前提下，不使用120米历史余料。净需求1345米，按倍数购1350米，采购行27000.00元。两方案的“新增采购支出差额”为2400.00元，不等同于利润增加或总成本节省；方案A消耗了有价值的现有库存。

**触发变化**：fixtures/02-late-material.txt把200米在途ETA改为需求日后。对当前供给分配重新核实后，该在途不得继续抵扣及时需求。此时使用120米库存方案净需求1425米、建议1430米、新增采购行28600.00元。不能只改风险标签而保持旧采购数。

**边界**：对未来交期给出“约束未满足/存在缺口”，不编造延期概率。缺少工厂产能不能承诺某方案保证准交。正式变更需要新预览、批准与版本核验。

## 场景三：材料先行开发与可解释复用

输入fixtures/03-material-development.txt。两个候选材料放入开发项目，对手感/缩水等没有测试结果的要求标记待测试。允许搜索历史相关材料与款式，结果来自数据库并显示相同点与差异。

关键词/结构过滤的候选显示“资料匹配”，不显示“视觉相似度98%”。接通视觉服务后再另行验收视觉功能。AI不能凭描述宣布物理性能合格。

采用某候选时建立引用和开发草稿，保留来源、版本及未确认项，不复制所有素材、不把历史客户批准自动迁移。

## 场景四：生产—余货—装箱—对账

此案例与场景一可使用另一订单，避免把不同口径硬凑成一个数据故事。

投产1020；有效报废10；在制15；合格995。其中实际出运980，未发运合格成品15。注意各工序增量记录不可当作全流程总产量重复相加。

生成逐箱款/色/尺明细，并检验总计980。箱重只有实际录入才是实测；装箱草稿、已装箱占用和正式发运分开。对账基准由演示组织配置并在界面可见，未配置则待核实。

本案例不产生实际付款，不连接承运商、不向客户发送信息。

## 场景五：安全与失败也是演示内容

带恶意指令的资料只作为不可信文本存档；工具调用要经过独立服务端授权。演示模型超时、缺失来源、版本漂移、跨工厂访问和重复点击，展示真实失败与修正路径。

“不做静态演示”包含失败路径：不能为了让演示顺滑而跳过权限、缺失字段和库存约束。
