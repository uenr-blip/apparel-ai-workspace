# 业务金额与总账核对

入口：财务与对账 → 会计账务 → 金额对账（/finance?tab=amounts）。本轮提供演示核对，正式会计政策与真实财务验收仍待确认。

## 两层核对

- 科目金额对照：明确选择应收、应付、资金、成本的科目集合，比较本组织全部已登记业务与本账簿已过账记录。原币分别列出，外币按明确的核对汇率折算；缺科目或汇率不按零处理。
- 来源凭证核对：原单、独立扣补、收付、退款、结汇分别追溯。按凭证原先留存的汇率/账面依据独立复算，不直接信任凭证自报总额；显示当前业务折算、原依据复算、有效借贷入账及差额。草稿不算已入账，已反向过账的原件净效应为零。

科目对照的核对汇率和凭证历史汇率用途不同。更改核对口径只改变比较结果，不修改凭证或自动重估；差异可能来自时点、舍入、期初、未入账或科目选择，须追查原因，不能直接按差额调账。

## 范围必须分清

1. 应收/应付比的是公司往来总额与选定科目净额，尚未逐客户或供应商做辅助余额对账。
2. 资金比的是已登记流水净变动与业务来源的资金分录净变动。手工资金分录及其反向记录单列，不能称为银行实际余额。外部银行真实性尚未核验。
3. 成本取已归单、已计价材料净耗用，加已确认加工及明确归集的其他费用。缺价、未归单或来源变化保留提示；不代表真实全部生产成本或正式成本结转。
4. 手工应收/应付/成本分录计入科目净额，但标明需人工核对来源。金额一致不证明科目使用正确、业务无遗漏或符合真实会计税务规则。

## 操作

选择账簿后，可先看来源凭证核对。具备账簿配置权限的人在「配置核对口径」弹窗选择科目、汇率日期和依据。科目必须属于本账簿且类别匹配，不能跨核对项目重复选择；支持暂留未确认项目。口径有版本和审计，过期表单不能覆盖更新。

进入「查看总账分录」，可看到相关已过账原件及反向分录，点凭证号核对。来源表可按订单/来源和结果筛选，每页20条。来源金额改变时，同时显示变化标记及可计算差额，不覆盖原凭证。

## 安全、容量与验收

读报告和查科目需要外贸查阅+总账查阅，保存口径另需账簿配置权限。组织、账号状态和权限由服务端重查；口径版本、幂等回执和审计同事务，原有账务记录不改动。

报告在同一事务快照内读取；来源和已过账凭证分别最多5000条，成本归集最多5000个来源；超限明确拒绝，不输出截断后的对平结论。映射每类最多50科目，共200科目；来源复算完成后再筛选分页，科目分录明细在数据库内分页。尚未证明生产容量。

整单模拟的结果与财务待确认事项见 [FINANCE_SIMULATION_ACCEPTANCE.md](FINANCE_SIMULATION_ACCEPTANCE.md)。schema不变，原演示库不导入验收账目，原3100不重启。正式账务切换、银行支付和税务申报仍未启用。
