# 财务与对账：外贸业务台账

2026-09-20。用户已授权外贸模块构建。本地mock；企业实际出口主体、会计制度、税务和银行规则未确认为生产规则。

## 已可办理

`/finance` 提供财务概览、外贸订单/应收、供应商/工厂应付、收付流水、出口单证，以及原来的加工草稿对账和材料凭证。

1. 外贸订单：关联已有业务订单，填写合同币种、金额、贸易术语/地点、出口模式及收款条款。出口模式可保持待确认；不默认订金比例或账期。详情显示已登记计划与待拆分金额。
2. 应收计划：分期登记订金、尾款或出运款，约定到期日，可关联实际已出运批次。有效应收计划总额不超过合同金额；超过20条仍按全量核算。草稿经授权确认后进入业务应收。
3. 应付：人工登记供应商/工厂应付依据，或引用采购/加工草稿。引用只生成草稿，须独立确认；来源变化、来源重复、金额或工厂不匹配会拦截。确认后来源再次变化会提示复核，原金额保留。
4. 收付流水：登记已发生的客户收款和供应商/工厂付款，保留币种、日期、账户标识、银行流水号及依据。费用单列；可保留有日期与来源的折算参考。不调用银行。
5. 核销：一笔流水可分配到同一往来方的多张单据，一张单据可分次核销。检查双方余额和当前版本；跨币种保留两边金额、汇率方向、日期与来源。撤回核销恢复余额并保留原记录。
6. 扣补/作废：确认后的单据通过独立扣补记录修正；不得将单据金额降到已核销额以下。单据或流水有有效核销时不能作废。原记录不删除。
7. 单证：登记合同、商业发票、装箱单、报关资料、银行回单和采购发票，可关联订单、单据、流水或出运批次。支持PDF/PNG/JPG私有附件、后补和鉴权下载；原件不能覆盖。
8. 概览/导出：应收、应付、收付本金及待分配金额按币种分别汇总；到期提醒用组织时区的实时日期。应收应付和流水可按筛选导出CSV并留审计，不冒充财务软件的正式记账凭证。

## 金额与业务口径

- 支持CNY、USD、EUR、GBP、HKD、JPY、AUD、CAD、SGD、CHF、KWD。货币精度明确配置，金额保存为最小单位整数；单笔上限999999999999999最小单位。汇率采用十进制计算，小数最多8位；折算按目标币种精度四舍五入，结果有两边金额及依据。
- 不同币种不直接合计，不自动抓取实时汇率，不用今日汇率覆盖历史。货币最小单位的概念参考[ISO 4217官方说明](https://www.iso.org/iso-4217-currency-codes.html)；支持列表不是对全部币种的承诺。
- 收款银行净额=款项本金−本方承担手续费；付款银行支出=本金＋本方承担手续费。核销以本金为上限，客户少付本金不能擅自记作手续费。
- 去重检查基于账户名称/尾号、银行流水号和方向；账户标识须统一填写。尚未建立与银行账户主档或银行流水导入的自动匹配。
- 有效应收即使因扣补变为零，也不能直接更换合同币种。旧草稿版本不能覆盖后续修改；幂等键对应确定请求内容，重试不重复记账。
- 当前收款登记面向客户，付款登记面向供应商/工厂。原币退款和结汇通过「资金调整」专用动作登记，不能用普通反方向流水绕过往来方检查；内部换汇流水不可再用于业务核销。复杂退款和坏账规则仍待扩展，见 [LEDGER_GUIDE.md](LEDGER_GUIDE.md)。
- 调拨不是领用，材料数量不是本单成本；既有加工草稿金额不是自动形成的正式应付或已付款。

## 权限与数据安全

经理可分别下发：外贸查阅、单据登记、业务确认与扣补、流水登记、核销/撤回、导出。写权限还需查阅权限；工厂账号不能查公司财务。既有加工对账授权不自动扩为外贸授权。

身份、组织和经办人均取自服务器当前用户；每次读写/下载/导出查权限。写入先取得数据库写锁再读取余额，业务记录、审计和幂等回执在同一事务提交。核销、扣补和作废保留历史。

SQL参数绑定；JSON请求限制64KiB，单证附件最多8MiB，类型与文件头一致；附件放私有目录，通过组织权限校验后以attachment/no-store/nosniff下载。浏览器写请求校验Origin与实际Host，不信任客户端角色或转发主机头。导出最多5000条并转义CSV公式。

## 开始使用

1. 经理进入「外贸订单/应收」→「登记外贸订单」，选择已有订单并填写结算条件。
2. 打开该订单→「新增本单应收」，按约定拆分金额与到期日；在单据详情核对并确认。
3. 在「收付流水」登记银行已发生记录，再进入单据「分配流水并核销」。多收款部分留在待分配额，不自动冲其他客户。
4. 应付按相同步骤登记/确认/核销；在「出口单证」上传原文件，或先登记编号再补原文件。

## 正式账务边界

业务单据确认不是总账过账；登记已付款不是发起银行支付。总账科目、期间控制、凭证/独立复核/过账/反向凭证以及有明确账面依据的结汇差额已在演示账套开放，见 [LEDGER_GUIDE.md](LEDGER_GUIDE.md)。正式会计/税务规则、期末重估、法定报表及真实银行连接仍未开放。

中国国际贸易单一窗口区分[生产版与外贸版](https://zj.singlewindow.cn/pen-portal/guide/basic.jspa?id=151)。出口主体、自营/代理模式、适用制度和申报规则需要财务确认；不凭“外贸”推定税务资格或自动计算退税。

## 运维与接入

新增8张Trade表及组合索引，未改旧业务表字段。当前服务使用参数化SQL访问新表，兼容运行中的Prisma 6客户端。`scripts/apply_trade_migration.py`仅允许本轮CREATE TABLE/INDEX，先备份、再校验旧表逻辑指纹与外键，不执行seed/reset或其他待执行迁移。

生产前仍需真实认证、角色职责分离、受信反向代理的Origin配置、银行账户标识、附件扫描、并发容量与备份恢复演练。当前分页20条、聚合与查询有界、SQLite本地并发测试不等于生产容量验收。
